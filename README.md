# 🌐 Folio – Personal Developer Portfolio

A modern and responsive portfolio website built using HTML, CSS, and JavaScript to showcase my projects, skills, and learning journey as a developer.

🔗 Live Demo: https://folio-poornendhu.netlify.app/

---

## 🚀 Features

- Responsive design for desktop and mobile devices
- Modern UI with clean layout
- Dark mode toggle
- Smooth scroll and reveal animations
- Project filtering by category
- Embedded Figma prototype showcase
- Skills section with animated progress bars
- Contact section with GitHub, LinkedIn, and Email links
- Performance optimized (90+ Lighthouse score)
